# Как помочь проекту

Спасибо, что хотите сделать еКонспект лучше! Ниже — как сообщить о проблеме и как прислать изменения.

## Сообщить о проблеме или идее
- Проще всего — кнопка **«Поддержка»** в окне расширения: откроется готовое письмо.
- Или **Issues** на GitHub — выберите шаблон: «Ошибка», «Не работает на моём тесте», «Идея».
- Уязвимости — только приватно, см. [SECURITY.md](SECURITY.md).

**Не публикуйте личные данные.** Сохранённые страницы курсов содержат ваше ФИО, ключ сессии (`sesskey`) и номера попыток. Не прикладывайте их к публичным issue и не выкладывайте скриншоты с ФИО. Если для разбора нужна страница — пришлите её письмом через «Поддержку», мы обезличим её сами.

## Прислать изменения
1. Node.js 24 и npm 11 (`.nvmrc`). Установка: `npm ci`.
2. Ветка от `main`, небольшой понятный pull request.
3. Перед отправкой: `npm run check` (типы, ESLint, Prettier, тесты, сборки, web-ext lint) — всё должно быть зелёным. Если меняли поведение на странице — `npm run e2e`.
4. Новый разбор разметки — с тестом и фикстурой.

### Правила кода
- Никакой записи HTML-строк (`innerHTML`, `insertAdjacentHTML`, `document.write`), `eval`, `new Function` — только `textContent` и `createElement`. Это проверяет ESLint.
- Сеть — только чтение страниц сайта курсов (GET). Никаких отправок форм, сторонних адресов, аналитики и удалённого кода.
- Новые разрешения в манифесте — только с обоснованием в PR и в `STORE.md`.
- Комментарии и тексты интерфейса — на русском, коротко и по делу.

### Фикстура по жалобе
1. Страница целиком (Ctrl+S → «Веб-страница, только HTML») или HTML блока `.que`.
2. `npm run sanitize-fixture -- страница.html test/fixtures/имя.html` — скрипт уберёт ФИО, id, `sesskey`, e-mail и сам проверит, что утечек нет. Проверьте результат глазами.
3. `npm run dump -- test/fixtures/имя.html --results` — что получится в TXT. Добавьте тест в `test/` и исправьте парсер.
